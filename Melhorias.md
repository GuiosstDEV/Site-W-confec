# Melhorias do catálogo de roupas

## Análise atual

O catálogo tem uma identidade visual marcante, com fundo azul, detalhes amarelos e destaque para um produto por vez. No entanto, a navegação funciona principalmente como uma apresentação de slides: há cerca de 31 produtos no mesmo carrossel, e é necessário avançar item por item para encontrar uma peça.

Esta análise foi feita com base nos arquivos do projeto, sem uma avaliação visual renderizada no navegador.

## Melhorias sugeridas

### 1. Facilitar a busca por categoria

Adicionar atalhos ou filtros para categorias como **Casual**, **Escolar**, **Corporativo**, **Operacional**, **Inverno** e **Esportivo**. Outra possibilidade é apresentar os produtos em uma grade filtrável. Assim, o visitante encontra o que procura sem percorrer todos os itens.

### 2. Corrigir imagens ausentes e revisar o catálogo

As imagens de jaqueta e blusa de inverno estão com o endereço vazio no HTML e podem aparecer quebradas. Também é importante verificar se todos os itens anunciados têm uma imagem correspondente e se os nomes e descrições estão corretos.

### 3. Priorizar a experiência em celulares

O cabeçalho reserva bastante espaço para a navegação e os títulos usam tamanho grande. Convém ajustar o layout para telas menores, incluindo cabeçalho, imagens, textos, botões e controles do carrossel. O CSS atual inclui uma regra para reduzir animações, mas não foram identificadas regras específicas de layout responsivo.

### 4. Tornar o contato mais útil

O botão de WhatsApp poderia abrir a conversa com uma mensagem inicial que identifique o produto, por exemplo: “Olá, tenho interesse em camiseta escolar”. Isso ajuda a contextualizar o contato desde o início.

### 5. Finalizar a navegação e a apresentação

O título da página ainda está como “Site TESTE”. Além disso, os itens “HOME”, “ROUPAS” e “SOBRE” aparecem como texto, sem links de navegação. Vale definir o título final e transformar esses itens em links funcionais, de acordo com as seções que forem mantidas no site.

## Ordem recomendada

1. Corrigir as imagens ausentes e revisar os dados dos produtos.
2. Ajustar o layout para celulares.
3. Implementar filtros ou atalhos por categoria.
4. Melhorar o botão de contato com uma mensagem contextualizada.
5. Finalizar o título da página e os links de navegação.

Depois dessas melhorias, pode ser útil complementar os produtos com informações como tecidos, tamanhos, cores e opções de personalização, desde que esses dados estejam disponíveis e confirmados pela empresa.
